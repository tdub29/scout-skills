# difficult-conversation

This hub collapses 61 atomic conversation skills into one router plus references. Route by user cue, read the referenced file(s) in full, and apply that framework exactly.

Book provenance: Patterson et al. *Crucial Conversations* (cc-*), Stone/Patton/Heen *Difficult Conversations* (stone-*), Marshall Rosenberg *Nonviolent Communication* (rosenberg-*), Chris Voss *Never Split the Difference* (voss-*), Charles Duhigg *Supercommunicators* (duhigg-*), Dale Carnegie *How to Win Friends and Influence People* (carnegie-*), and Michael Wheeler *The Art of Negotiation* (wheeler-*).

## When to use

Use this hub when the user explicitly needs help with a difficult conversation, conflict resolution, negotiation, feedback exchange, relationship repair, or high-stakes interpersonal communication.

## Guardrails

- Do **not** steal requests owned by unrelated skills when conversation-conflict intent is absent (e.g., pure marketing copy, SEO, coding architecture, finance analysis, legal drafting).
- Do **not** treat this hub as clinical therapy or crisis intervention; keep to communication frameworks.
- Do **not** answer from router memory alone; load the selected reference file(s) first.
- Keep routing tight: start with 1-2 references, expand only when the user asks for a combined method.

## Workflow

1. Confirm the user's intent is conflict conversation, negotiation, feedback, or repair.
2. Pick the closest row(s) in the routing table.
3. Read those `references/*.md` files completely.
4. Apply framework steps and output structure from those references.
5. If stuck, escalate by adding one complementary family (e.g., CC + Stone, Voss + Rosenberg).
