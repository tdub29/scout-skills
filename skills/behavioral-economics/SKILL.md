# behavioral-economics

This hub collapses 39 atomic behavioral-economics skills into one router plus references. Route by user cue, read the referenced file(s) in full, and apply that framework exactly. The families are Kahneman's *Thinking, Fast and Slow* (`kahneman-*`, 16), Ariely's *Predictably Irrational* (`ariely-*`, 12), and Kahneman/Sibony/Sunstein's *Noise* (`noise-*`, 11).

## When to use

Use this hub when the user wants to:

- Recognize, debias, or deliberately exploit a cognitive bias or heuristic.
- Estimate a number, cost, duration, probability, or risk and worries the estimate is distorted.
- Design or detect anchoring, framing, defaults, decoys, expectations, or pricing effects.
- Reduce unwanted variability (noise) in recurring judgments â€” ratings, scores, hiring, forecasts, reviews.
- Audit honesty, ownership/endowment, expectations, or the cost of keeping options open.
- Apply behavioral science to personal-finance, budgeting, or investing decisions.

## Guardrails

- Do **not** answer from router memory alone; load the selected reference file(s) before applying a framework.
- Keep routing tight: start with the 1-2 closest references; expand only when the user asks for a combined method (e.g., anchoring + prospect theory).
- Do **not** steal requests owned by unrelated hubs when no behavioral-economics intent is present â€” conflict-conversation/negotiation belongs to `difficult-conversation`, marketing persuasion copy to `persuasion-copy`, data viz elsewhere.
- Knowing about a bias does **not** make anyone immune to it; prefer structural defenses (pre-commitment, blind procedures, independent aggregation) over introspection.
- For the *Noise* family, distinguish noise (variability) from bias (systematic direction) before prescribing a fix.

1. Confirm the intent is behavioral-economics: a bias/heuristic to spot or exploit, an estimate to debias, choice architecture to design/detect, or noise to measure/reduce.
