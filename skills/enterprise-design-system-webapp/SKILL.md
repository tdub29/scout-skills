description: Create and enforce an enterprise-grade web design system for marketing and product routes. Use when defining tokens, typography, component primitives, responsiveness, and accessibility rules.
---

Apply tokenized design decisions before page-specific styling.

Define and reuse:
- Color, spacing, radius, elevation, motion tokens
- Typographic scale and semantic text styles
- Shared containers and panel primitives
- Mobile-first responsive breakpoints

For each screen:
1. Keep hierarchy obvious at first glance.
2. Preserve strong contrast and keyboard focus behavior.
3. Limit one primary CTA per section.
4. Reuse existing primitives instead of adding ad-hoc styles.

Use references/design-guidelines.md for checks.
