Write conversion copy with clear trigger, value, and next step.

Rules:
- State exactly why upgrade is required.
- Keep plan limits explicit.
- Tie upgrade CTA to newly demonstrated value.
- Avoid manipulative urgency language.

For each conversion surface provide:
- Headline
- Trigger reason
- Benefit bullets
- Primary CTA
- Secondary CTA

Use references/conversion-prompts.md templates.
