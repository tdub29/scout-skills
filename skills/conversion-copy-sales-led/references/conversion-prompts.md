# Conversion Prompt Templates

Every surface fills all five fields that SKILL.md requires, in this order.

## Blank template
- Headline: <what changed, in plain words>
- Trigger reason: <the exact limit or event that fired this prompt>
- Benefit bullets:
  - <value the user just saw, now without the limit>
  - <second concrete benefit, tied to their workflow>
- Primary CTA: <the one next step>
- Secondary CTA: <the low-pressure alternative, never a dark pattern>

## Upgrade required prompt
- Headline: Upgrade required
- Trigger reason: Free upload already used or file exceeds free size limit
- Benefit bullets:
  - Continue processing larger or multiple reports with the same workflow
  - Keep the results you just generated in one place
- Primary CTA: View pricing
- Secondary CTA: Talk to sales
