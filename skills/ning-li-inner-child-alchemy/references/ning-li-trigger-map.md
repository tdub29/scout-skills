# Ning Li: Trigger Map (Step 1)

## When to use

Trigger when starting **one release cycle** and the user has a live emotional charge but no structured map. Concrete cues:

- "What's bothering me right now?"
- Recurring fight with partner, boss, parent, or self
- Addiction/substance, money, body image, or porn shame loops
- User wants to journal before inner-child visualization
- Multiple issues â€” need to prioritize one trigger

Don't trigger for: memory retrieval (`references/ning-li-memory-link.md`), explaining why scripts exist (`references/ning-li-memory-script-model.md`).

## The framework

### Core thesis

You can only release what you can **see**. Step 1 builds self-awareness on **one** trigger: situation â†’ emotions â†’ thoughts â†’ behaviors. Li calls the first three steps "all about self-awareness"; release power scales with clarity.

Pick **one** trigger per session. Big releases are emotionally taxing â€” prefer end-of-day timing; not before high-focus obligations.

### Trigger domains (pick one)

Work, romantic relationship, friendship, money, sex/porn, food/body, family, substance/addiction, or "what's first on my mind when I wake up."

### Emotion taxonomy

Tag all that apply: anger/frustration/resentment; fear/anxiety/worry; shame/humiliation/low self-worth; guilt (against own moral code); pain/boredom/sadness.

### TRIGGER / REACTION template

```
When ____________, I feel ____________  (emotions)
When ____________, I think ____________  (thoughts)
When ____________, I tend to __________  (behaviors)
```

No self-judgment â€” all thoughts/feelings valid for mapping.

### Intensity rating

Rate emotional charge 1â€“10 on this trigger. Highest intensity = best candidate for next memory-link step.

## How to apply (step-by-step)

1. **Surface the trigger.** Journal prompt or lie-down + breathe until the charged issue surfaces.

2. **Domain tag.** One category from list above.

3. **Emotion sweep.** List all applicable emotions.

4. **Thought & behavior patterns.** Answer: *What are my patterns of thought, emotion, and behavior around this issue?*

5. **Write 2â€“4 TRIGGER/REACTION lines** using template.

6. **Intensity score** (1â€“10) with one sentence why.

7. **Output trigger map worksheet** (markdown table or bullets) ready for `references/ning-li-memory-link.md`.

8. **Disclaimers.** Not therapy; emotionally intense; if on medications that flatten affect, note possible impact on process (Li's caveat â€” defer to prescriber).

## Common failure modes

- **Too many triggers at once.** Force single focus; park others on backlog list.

- **Skipping behaviors.** Behaviors reveal script recreation; include them.

- **Moralizing thoughts.** Map without fixing â€” judgment blocks honesty.

- **Low-intensity pick.** User chooses easy topic to avoid pain; suggest highest charge they're willing to touch.

- **Skipping intensity score.** Needed to prioritize linked memories later.
