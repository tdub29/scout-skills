# Ning Li: Block Recreation Audit (Step 3)

## When to use

Trigger when memory + block type are known; user needs **bridge to today**. Concrete cues:

- "I get angry at myself like my dad did"
- Wife/caretaker example: repeats childhood role with siblings
- User sees trigger domain perfectionism linked to school pressure memory
- Step 3 before first reparenting release

Don't trigger for: block taxonomy (`references/ning-li-six-blocks-diagnosis.md`), release session (`references/ning-li-reparenting-protocol.md`).

## The framework

### Core thesis

Step 3 makes recreation **conscious**. Pick the **most charged memory** from Linked Memories list. Name the block in that scene, then name parallel behavior/thought/feeling in current trigger domain.

## How to apply (step-by-step)

1. **Inputs:** Primary linked memory + block diagnosis (+ trigger map if available).

2. **Block-in-memory statement.** "In this memory, the block is: ___"

3. **Scene behavior.** Parent/caretaker action that installed block.

4. **Adult self-recreation.** Specific thoughts, emotions, behaviors copying the pattern.

5. **Optional other-recreation.** Partners, kids, colleagues if relevant.

6. **Crosswalk to trigger map.** Match TRIGGER/REACTION lines to recreation.

7. **Output recreation audit** (table or bullets).

8. **Readiness gate:** User sees copy pattern clearly â†’ `references/ning-li-reparenting-protocol.md`.

## Common failure modes

- **Blaming present partner for past.** Focus on user's script replay, not partner diagnosis.

- **Only external recreation.** Missing internal self-parent voice â€” most common.

- **Vague "trauma caused this."** Require specific copy mechanism.

- **Skipping charged memory pick.** Work one memory; don't diffuse across list.
