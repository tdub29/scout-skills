## The framework

### Core thesis

Two brain systems: the **thinking brain** (words, sentences, running commentary) and the **emotional brain** (feelings, images, somatic charge). The emotional brain **holds the leash** â€” it sets the mood, and thoughts follow. You cannot think your way out of a script the emotional brain is already running.

The emotional brain is programmed by **memory scripts**, especially from ages **3â€“18**, when the brain is "spongy" and learns survival patterns from primary caregivers and immediate family. Every situation triggers a scan: *what memory shows how to react to this?* The script runs; you get matching emotions and thoughts. It feels like personality or "just how things are."

**Reprogramming** (in Li's method) means changing the emotional charge stored in specific memories â€” not deleting memory, but releasing it as an active playbook.

### The leash metaphor

Thinking brain = dog on a leash. Emotional brain = owner. Tugging (positive thinking, arguing) doesn't change direction until the owner moves. Anger, shame, joy, and numbness each recruit thought content that matches the emotion.

### Childhood memory bank

Scripts are stored from what caregivers **said**, **demanded**, **modeled**, and **punished**. The brain generalizes: one charged McDonald's meal, one report card, one silent dinner â€” each can become a reusable script for whole categories of life.

### First-time exercise (diagnostic)

For any charged topic: *When was the first time I felt this way?* Visualize a child self (5â€“14). The first memory that surfaces with charge is likely the script anchor for that adult trigger.

## How to apply (step-by-step)

1. **Name the live pattern.** One domain (work, romance, money, body, family, substance). One recurring emotion + typical thoughts.

2. **Map the leash.** Quote 2â€“3 thoughts that appeared *after* the emotion spiked (not before). Confirm emotion-led sequence.

3. **Hypothesize the script.** What "playbook" would a child learn to survive this? (Perform, hide, caretaker, freeze, rebel, please.)

4. **Run first-time probe.** Ask when they first felt this way; note age band and who was present.

## Common failure modes

- **Intellectualizing.** User agrees with the model but skips somatic/emotional contact. Route to trigger map or inner-child dialogue, not more theory.

- **Blaming parents as villains.** Model is explanatory, not indictment. Parent scripts came from *their* scripts.

- **Age-range rigidity.** 3â€“18 is emphasis, not exclusion; trust first charged memory.

- **One mega-script for everything.** Often multiple scripts; don't force unification in one pass.

- **Promising instant cure.** Li claims releases can permanently loosen a trigger; agent describes mechanism, doesn't guarantee outcomes.
