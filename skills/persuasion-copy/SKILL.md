# persuasion-copy

This hub collapses 46 atomic persuasion / rhetoric / advertising-classics skills â€” drawn from Cialdini (*Pre-Suasion* and *Influence*), Ogilvy (*Ogilvy on Advertising*), Hopkins (*Scientific Advertising*), Heath (*Made to Stick*), Aristotle (*Rhetoric*), and Heinrichs (*Thank You for Arguing*) â€” into one router plus references. ## When to use

Use this hub when the user explicitly wants a **named classical framework** applied to persuasion, rhetoric, or advertising â€” pre-suasion and priming (Cialdini), ethos/pathos/logos and the rhetorical genres/style/arrangement (Aristotle), argument construction and fallacy spotting (Heinrichs), advertising-classics discipline like the big-idea gate, reason-why copy, and test campaigns (Ogilvy/Hopkins), or the SUCCESs stickiness checklist (Heath). The right answer comes from one of these specific authors' frameworks, not from generic copy or marketing advice.

## Guardrails

- This hub is the **named-classical-framework** router only (Cialdini / Ogilvy / Hopkins / Heath / Aristotle / Heinrichs). For hands-on landing/marketing **page** copy use `copywriting`. For general **consumer-psychology** framing use `marketing-psychology`. For **headline punch-up** use the `schwartz-*` skills (e.g. `schwartz-headline-strengtheners`).
- Do **not** steal requests owned by these pre-existing skills outside this hub: `copywriting`, `marketing-psychology`, the entire `schwartz-*` family, `ad-creative`, `creative-strategy`, `marketing`, `marketing-ideas`, `cold-email`, `emails`, `cro`.
- Do **not** trigger for generic copywriting, SEO, or unrelated strategy work unless the user explicitly asks for one of these six authors' frameworks.
- Do **not** answer from router memory alone; load the selected reference file(s) first and follow their process and output format.
- Keep routing tight: start with 1â€“2 references; combine families only when the user asks for a multi-lens pass (e.g., Cialdini pre-suasion + Heath stickiness for a high-stakes appeal, or Aristotle modes + Heinrichs concession jujitsu for an argument).
- **Ethical guardrail:** several references (Cialdini Unity, ethical pre-suasion, post-suasion aftereffects) carry manipulation-risk checks â€” apply them when the reference requires it.
