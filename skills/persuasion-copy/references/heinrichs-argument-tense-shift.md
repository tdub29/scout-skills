# Heinrichs: Control the Tense

## The Framework

> The three core issues: blame, values, choice. Blame = past. Values = present. Choice = future. (Chapter 3)

Heinrichs's most useful operational move is to control the tense of an argument. Past-tense arguments assign blame. Present-tense arguments judge values. Future-tense arguments compare choices. If the goal is to get peace, agreement, or action, the future is usually where persuasion can work.

### Three Sub-Rules

**1. Diagnose the current issue.**

Blame asks "Who did it?" Values ask "Is this right or wrong?" Choice asks "What should we do?"

**2. Match tense to goal.**

Use past tense for accountability, present tense for praise/blame or values, future tense for decisions. Do not ask for a future decision while speaking the language of accusation.

**3. Shift with a practical question.**

"How will blaming me help us win the next contract?" / "Whether that's fair or not, what would work from here?" / "What choice gives us the best advantage?"

**4. Define the issue favorably.**

When you ask "How are we going to...?" make sure the question frames the choice in a way that supports your goal.

## How To Apply

Create an argument-tense diagnosis:

1. **Quote the argument.**
2. **Label the dominant tense.** Blame/past, values/present, choice/future.
3. **Name the desired outcome.**
4. **Decide whether a tense shift is ethical and useful.**
5. **Write a future-choice question.**
6. **Offer two concrete options.**

## Common Failure Modes

- **Trying to decide in blame tense.** "Who caused this?" rarely produces "what should we do now?"
- **Moralizing a practical choice.** Present-tense values can turn a solvable problem tribal.
- **Using future tense to dodge accountability.** If accountability is actually required, a choice shift can feel evasive.
- **Defining the choice against yourself.** "How can we stop being so careless?" starts with guilt rather than advantage.
- **Fact-checking when choice is needed.** Some deliberative questions depend on probability and values, not settled facts.
