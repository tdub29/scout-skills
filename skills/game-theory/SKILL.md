# game-theory

This hub collects ten game-theory frameworks â€” drawn from Dixit & Nalebuff (*The Art of Strategy*), Schelling (*The Strategy of Conflict* and *Micromotives and Macrobehavior*), and Axelrod (*The Evolution of Cooperation*) â€” into one router plus references. Route by user cue, read the referenced file(s) in full, and apply that framework exactly.

## When to use

Use this hub when the user faces a **strategic interaction** â€” a situation where the best move for one party depends on what the other parties do, and each party knows the others are reasoning the same way. Typical intents: "model this as a game," "what's the equilibrium," "should I move first or wait," "how do I make this threat / promise believable," "they keep undercutting us â€” is this a prisoner's dilemma," "how do I get cooperation without an enforcer," "where will we both end up if neither of us can talk," "why did this neighborhood / market / meeting tip," "should I randomize," "how risky is this standoff." The right answer comes from one of these four authors' game-theory frameworks, not from generic planning or persuasion advice.

## Guardrails

- This hub is the **named game-theory** router (Dixit/Nalebuff, Schelling x2, Axelrod). It models *strategic structure* â€” players, moves, payoffs, equilibria, dynamics.
- For interpersonal **negotiation or a hard conversation**, use `difficult-conversation`. For **power / status / influence tactics**, use `greene-48-laws`, `machiavelli-prince`, or `sun-tzu-art-of-war`. For **cognitive biases / consumer behavior**, use `behavioral-economics` or `marketing-psychology`. For **persuasion / rhetoric frameworks**, use `persuasion-copy`. Cross-reference these but do not modify them.
- Do **not** trigger for generic strategy decks, roadmapping, or single-actor decision-making (no interdependence) unless the user wants a Dixit/Nalebuff, Schelling, or Axelrod framework applied.
- Do **not** answer from router memory alone; load the selected reference file(s) first and follow their process, failure modes, and output format.
- Keep routing tight: start with 1-2 references; combine families only on a multi-lens pass (e.g., Dixit dominance + Axelrod tit-for-tat for a repeated pricing game, or Dixit credibility + Schelling brinkmanship for a standoff).
- **Manipulation-literacy convention (workspace-wide):** whenever a reference covers an *offensive* tactic â€” threats, brinkmanship, commitment devices, information-hoarding, exploiting a tipping cascade â€” pair it with a discrimination note: (1) **name the move**, (2) **model the payoffs** so it is legible, (3) **flag coercion vs. a legitimate commitment** (does it create value or only extract it; is it reversible; would the other side endorse it if they saw it coming), and (4) offer an **ethical / cooperative alternative**. The references that carry offensive tactics state this guardrail inline.
