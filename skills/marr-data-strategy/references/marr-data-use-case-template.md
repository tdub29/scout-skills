
# Marr: Data Use Case Template

## When to Use

Use when a data, analytics, or AI idea needs to become concrete enough to approve, prioritize, or reject.

## Do Not Use For

Already-approved implementation plans unless the use case was never scoped.

## Framework

Marr's use-case template connects every data initiative to strategy, ownership, data customers, data needs, governance, analytics, technology, skills, and implementation realities.

## How to Apply

1. Capture the use case in one sentence with a verb and business noun.
2. Tie it to a strategic goal before discussing tools.
3. Define success metrics and decision cadence.
4. Name owner and data customers separately.
5. Inventory required data and mark gaps.
6. Run governance and ethics checks early.
7. Identify analytics, technology, and skills only after the business and data needs are clear.
8. State how insight becomes action and how results will be monitored.

## Output Format

- Use case name.
- Strategic goal and objective.
- Success metric(s).
- Owner and data customers.
- Data requirements and gaps.
- Governance/ethics risks.
- Analytics, technology, and skills requirements.
- Implementation path and next decision.

## Common Failure Modes

- Starting with a tool or model instead of the strategic goal.
- Naming an executive sponsor but no tactical owner.
- Treating dashboard viewers as data customers when they cannot act.
- Listing available data instead of required data.
- Postponing privacy, consent, or quality issues.
- Declaring success with activity metrics that do not prove business outcomes.
