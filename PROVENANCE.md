# Skill provenance

This catalogue separates recorded origins from authorship claims. A bundle being in this repository does not mean Trevor White wrote it. Sources come from the workspace import records and published skill metadata, reviewed October 19, 2026.

## Labels

- **Vendored / imported:** an external skill source is recorded. This does not assert that the current copy is unchanged from upstream; exact modification history has not been reconstructed.
- **Adapted / source-derived:** the source record describes a local adaptation, synthesis, or instructions derived from a book, article, or other source. Credit remains with the source authors for their work.
- **Created locally (recorded claim, unverified):** the source record claims local creation. That claim has not been independently established as original authorship.
- **Unresolved origin:** the record is missing, ambiguous, or only describes copying from another local tree. Local copying is not evidence of authorship.

No skill bundle is certified as an original creation by this audit. The search/ranking script is maintained as project tooling separately from these skill bundles. Upstream revisions below are recorded evidence, not verified baselines.
